# Komorebi（木漏れ日）

Chromium（Electron）エンジンで動く、自作のデスクトップブラウザ（Windows用）。
中身は本物の Chrome と同じ Blink / V8 なので、たいていのサイトはそのまま表示できます。
旧名称は Deluxe Browser。初回起動時に、ブックマーク・履歴・ログイン状態などを自動で引き継ぎます。

## 起動

```bat
run.bat
```

または

```bash
npm install
npm start
```

exe にするには `npm run dist`（`dist/` に NSIS インストーラが出力されます）。

## 他のブラウザと違うところ

| 機能 | 内容 |
|---|---|
| **コマンドパレット** `Ctrl+K` | タブ・ブックマーク・履歴・全コマンドをあいまい検索。`>`コマンド `@`タブ `*`ブックマーク `?`履歴 で絞り込み。**計算**もできる（`1+2*3` → 7、Enterでコピー） |
| **ワークスペース** | 「仕事」「趣味」など色分けしたタブのグループを切り替え。`Alt+1〜9`。ワークスペースごとに別のタブ群 |
| **縦タブ** `Ctrl+Shift+L` | 上の横タブ ⇔ 左の縦タブ。サイドバーは折りたたみ可。ドラッグで並べ替え |
| **分割表示** `Alt+S` | 2つのタブを左右に並べる。リンクの右クリック →「横に並べて開く」も可 |
| **集中モード** `Ctrl+Shift+F` | 時間を決めて、YouTube・X など気が散るサイトをブロック（サイト一覧は設定で編集）。残り時間をツールバーに表示 |
| **リーダーモード** `F9` | 本文だけを抽出して表示。文字サイズ・テーマ（白/セピア/黒）、読了時間つき |
| **要素ブロッカー** `Ctrl+Shift+X` | ページ上の邪魔な要素をクリックで消す。**サイトごとに記憶**され、次回以降も消えたまま |
| **広告・トラッカーブロック** | 主要な広告/計測ドメインへの通信を遮断。ブロック数をツールバーに表示。サイトごとに ON/OFF |
| **HTTPS 自動アップグレード** | `http://` を `https://` に。開けないサイトは自動でHTTPに戻す |
| **追跡パラメータ除去** | `utm_*` `fbclid` `gclid` などをURLから自動で取り除く。`Ctrl+Shift+C` で除去済みURLをコピー |
| **強制ダークモード** `Ctrl+Shift+D` | サイトごと（または全サイト）。設定はサイトごとに記憶 |
| **タブの自動休止** | 使っていないタブのメモリを解放（既定15分）。再起動時のタブ復元も「休止状態」で復元するので軽い |
| **サイトごとのズーム記憶** | `Ctrl +/-/0` |
| **スクリーンショット** | `Ctrl+Shift+S`（表示範囲）/ パレットから「ページ全体」（縦長ページも1枚）。Pictures\Komorebi に保存＋クリップボードにコピー |
| **クイックメモ** `Ctrl+Shift+N` | サイドパネルのメモ帳。ページ上の文字を選択 → 右クリック →「選択範囲をメモに追加」（URL付き） |
| **アドレスバーの検索ショートカット** | `yt ねこ` `gh electron` `map 東京駅` `w 木漏れ日` など（一覧は設定画面） |
| **新しいタブページ** | 時計・時間帯で変わる背景・検索・ショートカット・TODO・集中モード |
| ほか | ページ内検索、ピクチャーインピクチャー、モバイル表示、ページの日本語翻訳、タブのミュート/ピン留め、閉じたタブの復元、ダウンロード管理、権限（カメラ等）の確認と記憶、ウィンドウの透明度・常に最前面 |

## ショートカット（主なもの）

| 操作 | キー |
|---|---|
| 新しいタブ / 閉じる / 閉じたタブを開く | `Ctrl+T` / `Ctrl+W` / `Ctrl+Shift+T` |
| タブ切替 | `Ctrl+Tab` / `Ctrl+Shift+Tab` / `Ctrl+1〜9` |
| ワークスペース切替 | `Alt+1〜9` |
| 戻る・進む・再読み込み | `Alt+←` `Alt+→` `Ctrl+R`（`F5`） |
| アドレスバー / パレット / 検索 | `Ctrl+L` / `Ctrl+K` / `Ctrl+F` |
| ブックマーク | `Ctrl+D`（パネル `Ctrl+Shift+O`） |
| 履歴 / ダウンロード / 設定 | `Ctrl+H` / `Ctrl+J` / `Ctrl+,` |
| ヘルプ（全コマンド一覧） | `F1` |
| 開発者ツール / 全画面 | `F12` / `F11` |

すべてのコマンドは `Ctrl+K` のパレットか `F1` のヘルプから探せます。

## データの保存先

- `%APPDATA%\komorebi\` に `settings.json`（設定）`sites.json`（サイトごとの設定）`bookmarks.json` `history.json` `notes.json` `session.json`（前回のタブ）、および Cookie 等
- スクリーンショット: `Pictures\Komorebi\`
- ダウンロード: 通常のダウンロードフォルダ（同名は `(1)` を付けて重複回避）

## 制限事項

- Chrome ウェブストアの拡張機能は使えません（Electron の制約）。
- 広告ブロックはドメイン単位です。YouTube の動画広告など、サイト自身が配信する広告は防げません。
- Google ログインは「安全でないブラウザ」と判定されるのを避けるため、UA から `Electron` を除去し、本物の Chrome が送るクライアントヒント（`Sec-CH-UA`）を付与しています。Google 側の判定が変わると弾かれる可能性があります。
- シークレットウィンドウ、アカウント同期は未実装です。
- ページ全体のスクリーンショットは縦 16000px までです。
- Electron 版は配布用のビルド（exe）を用意していません。使うときは下の「起動」のとおり自分でビルド・起動してください（配布は WebView2 版）。

## 構成

```
src/
  main.js          メインプロセス: ウィンドウ/タブ(WebContentsView)/コマンド/ネットワーク/IPC
  preload.js       外枠・オーバーレイ用ブリッジ（"k:" チャンネルのみ許可）
  page-preload.js  各タブ用。内部ページ(新しいタブ・集中モード画面)にだけAPIを出す
  lib/
    store.js       JSON永続化（遅延書き込み）
    blocklist.js   広告ドメイン一覧・追跡パラメータ除去
    pagescripts.js ページ注入スクリプト（リーダー/要素ブロッカー/PiP/ダーク）
  ui/
    index.html style.css renderer.js   ブラウザ外枠（タブ・ツールバー・ブックマークバー・検索バー）
    overlay.html overlay.css overlay.js コマンドパレット・アドレスバー候補・ダイアログ・右パネル
    newtab.html focus.html             新しいタブ / 集中モード画面
dev/
  selftest.js          自動テスト（70項目）
  selftest-restore.js  セッション復元テスト
```

## 自動テスト

実際にウィンドウを開いて機能を一通り動かします（一時プロファイルで動くので普段のデータには触れません。クリップボードは一時的に使い、終了時に元へ戻します）。
外部接続（example.com）を使う項目があります。テスト中はウィンドウを最小化・隠さないでください（画面に表示されていないとキャプチャ等が失敗します）。

```bash
npx electron . --selftest dev/selftest.js
# 続けてセッション復元の確認
KMR_KEEP=1 npx electron . --selftest dev/selftest-restore.js
```

PowerShell の場合は `$env:KMR_KEEP = "1"` を先に設定してください。スクリーンショットの出力先は環境変数 `KMR_OUT` で指定できます。
